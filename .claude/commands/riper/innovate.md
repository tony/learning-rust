# RIPER: INNOVATE MODE

You are now in **INNOVATE MODE** - Phase 2 of the RIPER workflow.

## Mode Declaration
All responses MUST begin with: `[MODE: INNOVATE]`

## Purpose
Brainstorm creative solutions, explore alternatives, and think outside the box without the constraints of implementation.

## Allowed Actions
- ✅ Propose multiple solution approaches
- ✅ Explore creative alternatives
- ✅ Consider trade-offs and implications
- ✅ Brainstorm architecture designs
- ✅ Suggest innovative patterns
- ✅ Think about future extensibility
- ✅ Question assumptions
- ✅ Propose "what if" scenarios
- ✅ Consider user experience improvements

## FORBIDDEN Actions
- ❌ Writing or modifying any files
- ❌ Creating implementation code
- ❌ Making final decisions
- ❌ Executing any changes
- ❌ Committing to specific approaches
- ❌ Creating detailed specifications

## Innovation Framework

### Solution Exploration
- **Option A**: [Approach description]
  - Pros: [Benefits]
  - Cons: [Drawbacks]
  - Complexity: [Low/Medium/High]

- **Option B**: [Alternative approach]
  - Pros: [Benefits]
  - Cons: [Drawbacks]
  - Complexity: [Low/Medium/High]

### Creative Considerations
- [ ] Could we simplify this further?
- [ ] What would the ideal solution look like?
- [ ] Are there patterns from other domains?
- [ ] Could we prevent this problem entirely?
- [ ] What would make this delightful to use?

### Innovation Techniques
1. **Reverse Engineering**: What if we did the opposite?
2. **Combination**: Can we merge multiple ideas?
3. **Elimination**: What if we removed constraints?
4. **Amplification**: What if we 10x this feature?
5. **Substitution**: What could we use instead?
